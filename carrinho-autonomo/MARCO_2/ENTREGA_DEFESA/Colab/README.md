# Colab - Marco 2

O [notebook principal](../../../colab/Carrinho_IESB_Agente_Marco2.ipynb) está
no caminho canônico do projeto. Abra-o no Google Colab para demonstrar A*,
tabela e gráfico das buscas, pergunta → ferramenta → resposta e uma falha
explicada. Ele incorpora as nove fontes Python de que precisa.

Os [guias públicos de defesa](../../../ENTREGA_DEFESA_MARCO2/README.md)
explicam os arquivos e os 15 resultados. Os documentos locais de entrega,
inclusive `AUTORES` e a minuta com matrículas, estão em
`../../../ENTREGA_DEFESA_MARCO2/` no computador do grupo.

Se o mapa do Webots for alterado, o notebook continua com o mapa incorporado
até ser regenerado e executado novamente. Não apresente as duas versões como
idênticas enquanto essa atualização e validação não forem concluídas.
